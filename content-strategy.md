# RAW Actor Studio Content Strategy

## Weekly Structure

Keep the cadence at three Instagram posts per week:

- Tuesday: Craft Education
- Thursday: Philosophy / Identity
- Saturday: Conversion / Social Proof

## Tuesday: Craft Education

Each Tuesday post must teach:

1. One acting problem
2. One tool
3. One practical application

Examples:

- Cold reads and first-pass choices
- Breaking down sides without overthinking
- Taking direction without losing specificity
- Self-tape prep under time pressure
- Building playable actions instead of vague emotion

CTA defaults:

- save / think / audit
- occasional class CTA only if the post naturally supports it

## Thursday: Philosophy / Identity

Thursday posts should clarify how RAW thinks, not just what RAW sells.

Use themes like:

- authorship
- clarity
- individualized coaching
- lineage-based contemporary teaching
- serious support
- repeatable systems
- acting as craft + profession

CTA defaults:

- book a free audit
- learn the system
- read the room / know what kind of training you need

## Saturday: Conversion / Social Proof

Saturday posts rotate between:

- enrollment push
- free audit CTA
- student spotlight
- RAW Reels proof-of-work
- class room proof / behind-the-scenes

Do not hardcode a simple even/odd pattern. Use weighted rotation so the feed does not feel templated.

## Funnel Priority

Default business priority:

1. Class enrollment
2. Free audit
3. RAW Reels

## Audience Stage Labels

Use these audience stages in generation:

- cold: curious actor with no relationship yet
- warm: knows RAW, comparing options, likely audit lead
- hot: close to booking a class or follow-up offer
- alumni: prior student or repeat actor

## Session-Aware Overrides

If an active session enters a sales window, allow Saturday to prioritize enrollment more heavily.

Suggested urgency stages:

- awareness
- enrollment_open
- social_proof_push
- last_spots
- final_call

When no verified session is active, fall back to audit, philosophy-backed conversion, or proof-of-work posts.

## Caption Rules

- Prefer tight captions over padded captions
- Use line breaks, but keep paragraphs compact
- One idea per post
- One CTA per post
- Hashtags stay brand-safe and platform-native
- Never pad a caption to hit a word count

## Proof Requirements

Each post must cite at least one of:

- official brand pillar
- faculty credential
- student proof
- offer fact
- human source note

## Anti-Repetition Rules

Track and avoid repetition across:

- opening hook
- sentence rhythm
- proof point
- CTA
- acting concept
- post angle

## Review Taxonomy

Review reasons should be recorded exactly as:

- too generic
- not RAW voice
- fact issue
- too salesy
- visual feels templated
